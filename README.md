# ✊ ✌️ 🖐️ Unity Rock Paper Scissors Game (가위바위보 게임)

유니티(Unity)와 C#을 기반으로 제작된 클래식 가위바위보 게임입니다. 플레이어와 컴퓨터가 대결하며, 먼저 5점을 달성하는 쪽이 승리하는 5점 선승제 규칙이 적용되어 있습니다.

---

## 🚀 주요 기능 (Main Features)

* **실시간 스프라이트 애니메이션**: 게임 진행 중 컴퓨터가 가위/바위/보를 순환하며 돌아가는 시각적 연출 제공
* **승패 판정 및 점수 실시간 갱신**: 플레이어의 선택과 컴퓨터의 랜덤 선택을 비교하여 라운드 결과 판정 및 점수 반영
* **5점 선승제 시스템**: 플레이어 혹은 컴퓨터가 먼저 5점을 획득하면 게임이 종료되고 결과 패널(UI Panel) 활성화
* **유연한 게임 제어**: 전체 초기화(`Reset`), 라운드 재시작(`Restart`), 게임 종료(`Exit`) 버튼 기능 지원

---

## 🛠️ 기술 스택 (Tech Stack)

* **Engine**: Unity
* **Language**: C#
* **UI Framework**: Unity UI (UGUI), TextMeshPro

---

## 🎯 구현 범위 (Implementation Scope)

* **플레이어 입력 처리**: 가위, 바위, 보 버튼 클릭 이벤트 연결 및 선택 상태(`Choice`) 관리
* **컴퓨터 AI 로직**: `Random.Range`를 활용한 무작위 선택 생성 및 승패 판정 알고리즘 구현
* **게임 루프 및 UI 연동**: 5점 선승제 규칙 적용, 점수판 텍스트 갱신, 결과 패널 제어 및 버튼 활성화/비활성화 처리
